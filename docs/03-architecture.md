# 架构

## 分层

```
┌──────────────────────────────────────────┐
│ UI 层      MainActivity / UiKit           │  纯代码布局，无 XML，无第三方库
├──────────────────────────────────────────┤
│ 状态层     设备列表 / 选中设备 / 程序选择   │
├──────────────────────────────────────────┤
│ 协议层     YQ · HNH · PULSE               │  统一 send(bytes) / onRx(bytes)
├──────────────────────────────────────────┤
│ 传输层     GATT 队列 + 写看门狗 + 连接看门狗 │  同一时刻只允许一个 GATT 操作
├──────────────────────────────────────────┤
│ 日志层     LogSink                         │  每行 flush，崩溃不丢
└──────────────────────────────────────────┘
```

## 关键设计

**1. GATT 写队列**
Android 同一时刻只允许一个 GATT 操作在飞。所有下发（握手帧、启动帧、明文指令）进 `Deque`，收到 `onCharacteristicWrite` 再放行下一帧；1.5s 无回调由看门狗强制放行。

**2. 协议自适应**
连接后按服务表判定协议：`fff0`→YQ，`fee9`→HNH（优先于 `fee8`），`ffe0/fee0/ff00`→PULSE。
启动后 2.6s 无任何回执，自动在 HNH ↔ 脉冲之间换协议重发，两轮失败才报错。

**3. 回调竞态**
每次连接持有 `currentGatt`，所有回调先判 `gatt != currentGatt` 直接丢弃——避免旧连接的迟到回调覆盖新连接状态。

**4. 设备识别（三级）**
1. 已知 MAC 映射（宿舍房间号）
2. 楼层机位号正则：`1-1` / `101` / `3F-2` / `3楼2` / `A1-3`
3. 服务 UUID 白名单

前置负向词表过滤耳机/音箱/手环（`BUDS`/`ENCO`/`JBL`/`BAND`…），解决通用 UUID 误命中。

**5. 排序防抖**
RSSI 走 0.2 EMA 平滑，列表用迟滞交换：下位设备要比上位高 7dBm 才允许上升，避免卡片乱跳。

## 构建

`app/build.sh`：`javac` → `d8` → `aapt2 link` → 塞 dex → `jarsigner`。
不用 Gradle，是为了在没有 Android Studio 的机器上也能一条命令出包；代价是要手动备好 `android-all.jar` / `r8.jar` / `apktool.jar`。
